# 🐧 Pingu 的小世界 · 给陈俊贤的 11 岁生日礼物

一份用 HTML + JavaScript 做的互动小礼物：**一个文件、不用装 App**，手机浏览器打开就能玩。
5 只 Pingu 用的是姐姐给的实拍图（**吃饭 → 上学 → 睡觉 → 滑雪 → 生日**，顺序没动，形象没重画），动作、过渡、音效按《Pingu 生日互动礼物 · 完整方案》实现，生日按**农历九月廿八**每年自动换算。

> v3 新增：**隔空手势（MediaPipe Hands）**。开启摄像头后，左手动一动 = 点圆盘动作，右手左右滑 = 切换 Pingu；原有的点击玩法完整保留，随时可以关掉摄像头。
>
> **v3.1 修复**：之前出现的 `hands_solution_packed_assets.data` 报错（表现为摄像头能开、手势没反应、顶部红条）已处理：加了 MediaPipe 资源加载兼容层、主 CDN 换到更稳定的版本、双 CDN 自动回退、显式 `initialize()` 和 20 秒超时提示；并用「canvas 假摄像头 + 合成关键点」跑通了完整链路（模型初始化 → 出结果 → 左手 A/B → 右手切角色）。建议用下方 **localhost 或 https** 方式打开，别直接双击 `index.html`。

## 一、手机上怎么打开

### 方案 A（本地预览）：电脑和手机连同一个 WiFi

1. 双击 **`启动手机版.bat`**。
2. 窗口里会出现网址，例如 `http://192.168.x.x:8000/`（会自动复制到剪贴板）。
3. 手机连**同一个 WiFi**，浏览器输入「手机打开」的网址。
4. 想停止：窗口里按 `Ctrl + C`。

> 注意：`http://` 局域网模式下，**隔空手势按钮会自动隐藏**（浏览器安全限制，摄像头不允许），但点击圆盘、滑动、打招呼全部正常。

### 方案 B（推荐：生日当天最稳，也能用隔空手势）：免费部署到网上

1. 注册 GitHub：<https://github.com>
2. 新建仓库 `New repository` → 名字随意（如 `pingu-gift`）→ 选 **Public** → `Create repository`。
3. 点 `uploading an existing file`，把 **`index.html`** 传上去 → `Commit changes`。
4. `Settings` → 左侧 `Pages` → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，`Save`。
5. 等 1～2 分钟，访问 `https://你的用户名.github.io/pingu-gift/`。

> 部署到 https 后：**隔空手势可用**、麦克风「🎤」出现（说「你好」「生日快乐」）。
> 如果要给弟弟发链接，直接用这个网址即可。

### 方案 C：安卓手机直接开文件（备用）

把 `index.html` 传到安卓手机，用「文件管理」找到它，选择用 **Chrome** 打开。
（iPhone Safari 不能直接开本地 html，请用方案 A / B。注意：`file://` 下摄像头权限可能被浏览器拒绝，隔空手势建议用方案 B。）

## 三、隔空手势（MediaPipe Hands）

### 怎么开启

1. 打开部署在 **https** 上的网址（或电脑本机 `localhost`）。
2. 点右下角 **「✋ 隔空」** 按钮（默认关闭）→ 浏览器询问摄像头权限 → 允许。
3. 第一次会联网下载手势模型（约几 MB，显示「正在加载手势模型…」），加载好后右上角出现小摄像头窗口。
4. 把手举到摄像头前（距离 40～70cm，整只手都在画面里），窗口下方会提示「左手 ✓ / 右手 ✓」。
5. 再点一次「关闭」按钮即可关摄像头。

### 手势规则（已按你的要求实现）

| 手 | 判定方式 | 触发 |
| --- | --- | --- |
| **左手**（handedness = Left） | 食指指尖在连续帧内位移超过画面 4.5%（180ms 窗口），**冷却 0.6 秒** | 调用 `__pingu.doAction()`，和点左下圆盘完全一样：切换 A/B 动作 |
| **右手**（handedness = Right） | 食指指尖横向位移超过画面 12%，且横向位移 > 纵向 1.8 倍（380ms 窗口），**冷却 0.7 秒** | 调用 `__pingu.nextCharacter(±1)`，和右手滑动一样：切换 Pingu，保留淡入淡出 + 「叮」 |

- 手刚进入画面会有 350ms 稳定期，避免"抬手"被误判。
- 两只手同时出现时可以各干各的：左手做动作、右手切角色。
- 识别在页面内本地完成（MediaPipe WASM），画面**不会上传**；关掉开关就停止摄像头。

### 可调参数

打开 `src/gesture-mediapipe.js`，顶部 `CFG`：

```js
SWAP_HANDS: false,       // 如果左右手识别反了，改成 true
INVERT_SWIPE: false,     // 如果右手滑动方向反了，改成 true

// 防误识别（没举手也在动时，优先调这几个）
MIN_HAND_SCORE: 0.75,    // 手的置信度
HAND_MIN_SPAN: 0.09,     // 手掌至少占画面 9%（太小 = 太远/误检）
HAND_CONFIRM_FRAMES: 3,  // 连续 3 帧都检测到才算
HAND_CENTER_MARGIN: 0.15,// 手必须在画面中间区域

LEFT_MOVE_THRESHOLD: 0.09,   // 左手：240ms 内指尖位移 > 画面 9%
LEFT_COOLDOWN_MS: 600,       // 左手防抖（要求 0.6s）
RIGHT_SWIPE_X: 0.16,         // 右手横向滑动阈值
RIGHT_COOLDOWN_MS: 700
```

改完在 `pingu-gift` 目录执行 `python src/build.py` 重新生成 `index.html`（或把需求发我改）。

### 防误识别说明（v3.2）

之前「没举手也在动」是因为手掌检测把画面边缘/背景误判成了手，指尖关键点轻微抖动就超过了阈值。现在触发一次动作要同时满足：

1. handedness 置信度 ≥ 0.75；
2. 手掌足够大（手腕→中指根 ≥ 画面 9%），排除太远/误检；
3. 手在画面中间区域，排除"拿手机的那只手"；
4. 连续 3 帧都检测到同一只手；
5. 左手：长窗口（240ms）位移 ≥ 9%，**并且**短窗口（80ms）还在往同一方向移动（纯抖动不会触发），触发后冷却 0.6 秒；
6. 右手：380ms 内水平位移 ≥ 16%，横向明显大于纵向，短窗口方向一致，冷却 0.7 秒。

识别时小窗会显示「左手 ✓ 动一动 / 右手 ✓ 左右滑 / 举起手试试」，只有真的举手才会出现 ✓。

### 兼容性与排错

- **只在 https / localhost 生效**；普通 `http://` 局域网会自动隐藏「✋ 隔空」按钮，不影响点击玩法。
- **千万不要直接双击 index.html（file://）测试隔空手势**：浏览器会限制 MediaPipe 拉取模型文件，表现为摄像头能开、但手势没反应，甚至报 `hands_solution_packed_assets.data` 相关错误。
  - 电脑上正确做法：双击 `启动手机版.bat`，用窗口里打开的 **`http://127.0.0.1:8000`**（localhost 属于安全环境，摄像头和模型都能用）；
  - 手机上正确做法：部署到 **https**（GitHub Pages）后打开。
- 需要**联网**：MediaPipe Hands 通过 CDN 加载（jsDelivr → unpkg 自动回退），首次加载约几 MB；国内网络偶尔较慢，页面会显示「正在加载手势模型…」。加载失败会给出提示，原玩法照常。
- 安卓 Chrome / Edge、iPhone Safari 15+ 都可以；旧浏览器可能不支持 WebAssembly。
- 左右手识别反了 → `SWAP_HANDS: true`；滑动方向反了 → `INVERT_SWIPE: true`。
- 太暗、手离太远、只露出一部分手都会影响识别；保持整只手在画面里、光线充足。
- 页面专门加了 **MediaPipe 资源加载兼容层**（`packedAssets/getPreloadedPackage` 兜底）和 **9 秒加载超时**，网络被拦截时不会再卡在「启动中」。
- 如果仍然失败：点开浏览器 **F12 → Console**，把红色报错截图发我；错误会同时显示在页面的提示条里。

> 快速判断环境：看地址栏。`file:///...` = 不能用手势；`http://127.0.0.1:8000` = 可以用；`https://...` = 可以用。

## 四、想改的地方

### 1. 名字 / 农历生日 / 年龄

搜 `配置区`：

```js
var CONFIG = {
  name: "陈俊贤",
  age: 11,
  lunarMonth: 9,   // 农历九月
  lunarDay: 28     // 廿八
};
```

农历→公历是实时计算的（已验证 2024–2028 年春节和 2026 年九月廿八），明年、后年都不用改。

### 2. 台词

搜 `var SCENES`，每个场景的 `lines` 就是 Pingu 说的话。
打招呼在 `function greet()`：`say("你好，" + CONFIG.name + "！")`、`speak(...)`。

### 3. 动作幅度 / 时长

搜 `var ACTIONS`：每个场景 `[A动作, B动作]`，`keys` 是关键帧（`t` 秒、`p` 位置/旋转/缩放），`sounds` 音效时间点，`fx` 粒子时间点。

### 4. 图片

五张图已抠成透明 WebP 内嵌在 `index.html` 里，不需要额外图片文件。原始图在 `src/`，重新生成：

```bash
python src/process_images.py   # 抠图 → src/cutouts/*.webp
python src/build.py            # 合成 index.html
```

### 5. 颜色

搜 `body[data-scene=`，每个场景的 `--bg1/--bg2` 就是背景色。

## 五、技术说明（写给正在学 AI 和计算机的你）

- **单文件**：`index.html` 约 393KB，图片以 base64 WebP 内嵌，CSS/JS 全内联；除隔空手势的模型外都离线可用。
- **图片**：Python + Pillow 自动抠白底（连通域 + 去白边 + 羽化）、去右下角水印，统一高度后压成 WebP。
- **动画**：JS 关键帧 + `easeOutQuad`，`<img>` 的 transform（位移/旋转/缩放），`transform-origin` 在脚底。
- **音效**：Web Audio 实时合成，没有任何音频文件。
- **语音**：`speechSynthesis` 朗读；`SpeechRecognition` 识别「你好 / 生日快乐」。
- **农历**：Meeus 朔望月 + 太阳视黄经，按「冬至月为十一月、无中气置闰」规则纯前端计算。
- **隔空手势**：独立的 `GestureMediaPipe` 模块（`src/gesture-mediapipe.js`），通过 CDN 加载 `@mediapipe/hands`，`getUserMedia` 取摄像头，WASM 本地推理；只调用页面已有的 `window.__pingu.doAction / nextCharacter`，与原有业务代码完全解耦。
- **适配**：竖屏 390×844、320×568、横屏 844×390 都测过；`100dvh` + 安全区适配刘海。

## 六、已知限制 / 下一步

1. 隔空手势要求 **https + 联网 + 摄像头权限**；三个缺一个就无法开启，但点击/滑动玩法不受影响。
2. 摄像头是让弟弟"对着空气挥手"，不是增强现实；后续可以加手部骨架画在小窗里、或让 Pingu 跟着指尖移动。
3. iPhone 静音键打开时语音可能没声音，调大媒体音量即可。
4. 实拍图和扁平卡通道具画风不同，这是"用你给的图、不重画"的必然结果。
5. 可以继续加：姐姐录音、弟弟照片、集齐 5 只的隐藏彩蛋、背景音乐。
