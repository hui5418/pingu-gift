# 🐧 Pingu 的小世界 · 给陈俊贤的 11 岁生日礼物

一份用 HTML + JavaScript 做的互动小礼物：**一个网页、不用装 App**，手机浏览器打开就能玩。
5 只 Pingu 用的是姐姐给的实拍图（**吃饭 → 上学 → 睡觉 → 滑雪 → 生日**，顺序没动，形象没重画），动作、过渡、音效按《Pingu 生日互动礼物 · 完整方案》实现，生日按**农历九月廿八**每年自动换算。

> **v4 更新**
> - 按你的要求：**隔空手势功能全部移除**（没有「✋ 隔空」按钮、没有摄像头、没有手势模型/CDN 依赖）
> - 左下角文案：**「左手点这里」→「点这里」**
> - 图片改为 **PNG + 8% 透明安全留白**，避免部分手机浏览器把叉子尖、帽子毛球、手臂边缘裁掉
> - 页面更小更稳，只保留点击圆盘 / 滑动 / 打招呼 / 麦克风 / 生日彩蛋

## 一、手机上怎么打开

### 方案 A（推荐：生日当天用这个）：电脑本地 HTTPS

1. 双击 **`启动手机版.bat`**（第一次会自动生成自签名证书，需要电脑装了 Git）。
2. 窗口里会出现两个网址：
   - `手机打开： https://192.168.x.x:8443/`
   - `电脑打开： https://127.0.0.1:8443/`
3. 手机连**同一个 WiFi**，用 **Chrome / Edge / Safari** 打开「手机打开」的网址。
4. 第一次会提示「证书不安全」：点 **高级 → 继续前往**（只是本地自签名证书，数据全在本机）。
5. 想停止：窗口里按 `Ctrl + C`。

> 这个方式下：**麦克风「🎤」可用**（需要 https），页面和图片全部从电脑本地加载，不依赖外网。
> 如果 Windows 弹防火墙提示，选「允许访问（专用网络）」。
> 手机不要用微信/QQ 等 App 内置浏览器。

### 方案 B：部署到网上（GitHub Pages）

仓库：<https://github.com/hui5418/pingu-gift>，线上地址：**https://hui5418.github.io/pingu-gift/**

> 部分地区/运营商会拦截 `github.io`（手机报 `DNS_PROBE_FINISHED_NXDOMAIN`）。
> 遇到这种情况：换 WiFi、手机 DNS 改成 `223.5.5.5`，或直接用方案 A 的本地 HTTPS（最稳）。

### 方案 C：安卓手机直接开文件（备用）

把 `index.html` 传到安卓手机，用「文件管理」找到它，选择用 **Chrome** 打开。
（iPhone Safari 不能直接开本地 html，请用方案 A / B。`file://` 下麦克风权限可能被拒绝，建议用方案 A。）

## 三、图片处理说明（v4）

5 张实拍图来自姐姐提供的原图（豆包 AI 生成，右下角水印已去除），处理流程在 `src/process_images.py`：

1. 自动识别白色背景并抠掉（只去掉与画面边缘连通的白底，保留角色内部白色）；
2. 统一裁到角色边界、缩放到 620px 高，保存为 WebP；
3. **新增 `src/pad_cutouts.py`**：在角色顶部和左右各加 8% 透明留白，转成 PNG 再内嵌进 `index.html`。

加留白的原因：部分安卓 WebView 渲染透明图片 / 大图时，会把图片**最外圈几个像素裁掉**——正好是叉子尖（左边缘）、帽子毛球（顶部）、手臂（右边缘）。加留白后，即使再被裁，裁到的也只是透明边，角色本身完整。

## 四、想改的地方

### 1. 名字 / 农历生日 / 年龄

`src/app.template.html` 里：

```js
var CONFIG = { name: "陈俊贤", age: 11, lunarMonth: 9, lunarDay: 28 };
```

### 2. 台词

搜 `LINES` / `bubbleText`，改对应文案即可。

### 3. 动作幅度 / 时长

`ACTIONS` 里每个形象有 `A`、`B` 两组关键帧（`P({x,y,r,sx,sy})`，单位是舞台坐标），改完在 `pingu-gift` 目录执行：

```bash
python src/pad_cutouts.py    # 只有改了图片才需要
python src/build.py          # 重新生成 index.html
```

### 4. 图片

换成新图后：先跑 `python src/process_images.py`（生成透明 WebP），再跑 `python src/pad_cutouts.py`，最后 `python src/build.py`。

### 5. 颜色 / 场景

场景是内联 SVG（`SCENES` + `bgArt` / `frontArt`），改 `src/app.template.html` 里的颜色值即可。

## 五、技术说明（写给正在学 AI 和计算机的你）

- **单文件**：`index.html`（约 1.9MB，含 5 张 base64 PNG）；CSS/JS 全内联，复制一个文件就能用。
- **场景**：400×460 的 SVG 舞台，背景层 + Pingu 图片层 + 前景层，`preserveAspectRatio="xMidYMid meet"`，手机横竖屏自动缩放。
- **动作引擎**：关键帧数组（`poseAt` + `easeOutQuad`），`requestAnimationFrame` 驱动，`transform-origin` 在脚底。A/B 两段式：第一次点触发 A，第二次点触发 B。
- **音效**：Web Audio API 现场合成（没有音频文件），每个形象一套专属音色。
- **语音**：`speechSynthesis` 朗读中文（pitch 1.3）；`SpeechRecognition` 识别「你好」「生日快乐」（需 https/localhost）。
- **农历**：`src/lunar.js` 用 Meeus 新月 + 太阳黄经 + 「冬至所在月为十一月 / 无中气置闰」规则换算农历九月廿八，已验证 2024–2028 年。

## 六、已知限制

- 线上 GitHub Pages 在某些网络会被 DNS 拦截，优先用方案 A 的本地 HTTPS。
- App 内置浏览器（微信/QQ/小红书等）不支持麦克风/部分渲染，请用 Chrome / Edge / Safari。
- 图片是实拍抠图，边缘是毛绒软边，放大看会有轻微锯齿，属正常。
- 没有后端、不收集任何数据；麦克风只有在你点击后才启用，关掉页面即停止。
